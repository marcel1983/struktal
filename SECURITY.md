# Seguridad

Struktal lee archivos de modelo que pueden no ser de confianza. Se consideran fallos de seguridad: caídas, consumo de memoria o tiempo sin límite, o escritura fuera de la ruta pedida al procesar un archivo de entrada.

Para informar de uno, usa **Security → Report a vulnerability** en GitHub (aviso privado). No abras una incidencia pública con un archivo que provoque el fallo.
